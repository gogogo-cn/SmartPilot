## 字段定义

| 字段名 | 键名 | 正则表达式 | 必填 | 可见 |
|--------|------|-----------|------|------|
| 银行名称 | bank_name | `(中国(?:工商|建设|农业|交通|招商|民生|光大|中信|兴业|浦发|邮储|华夏|平安|广发|渤海|恒丰|浙商)银行)` | 否 | 是 |
| 交易流水号 | serial_no | `(?:交易流水号|流水号|凭证号)[：:\s]*([A-Za-z0-9]{10,30})` | 否 | 是 |
| 交易类型 | trade_type | `(?:交易类型|摘要)[：:\s]*([^\n：:]{2,20})` | 否 | 是 |
| 交易日期 | trade_date | `(?:交易日期|日期|记账时间)[：:\s]*(\d{4}[\-/年]\d{1,2}[\-/月]\d{1,2}日?\s*\d{1,2}:\d{2}(?::\d{2})?)` | 是 | 是 |
| 付款人账号 | payer_account | `付款人(?:账号|账户)[：:\s]*([\d*]+)` | 否 | 是 |
| 付款人户名 | payer_name | `付款人(?:户名|名称)[：:\s]*([^\n：:]+)` | 否 | 是 |
| 收款人账号 | payee_account | `收款人(?:账号|账户)[：:\s]*([\d*]+)` | 否 | 是 |
| 收款人户名 | payee_name | `收款人(?:户名|名称)[：:\s]*([^\n：:]+)` | 否 | 是 |
| 金额 | amount | `(?:金额|交易金额)[：:\s]*[¥￥]?\s*([\d,]+\.?\d*)` | 是 | 是 |
| 币种 | currency | `(?:币种)[：:\s]*(人民币|美元|欧元|日元|港币|英镑)` | 否 | 是 |

## 解析脚本

```javascript
function parse(text) {
    var r = {};
    for (var i = 0; i < FIELDS.length; i++) {
        var f = FIELDS[i];
        if (f.pattern) {
            try {
                var rx = new RegExp(f.pattern);
                var m = text.match(rx);
                if (m && m[1]) {
                    r[f.key] = m[1].trim();
                }
            } catch (e) {
            }
        }
    }
    
    if (r.amount) {
        r.amount_clean = r.amount.replace(/,/g, '');
    }
    
    return r;
}
```
