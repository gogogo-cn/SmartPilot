图片放置说明
============

1. 微信二维码（必配）
   把「扫二维码，添加我为朋友」那张图命名保存为：

       wechat-qr.jpg

   放到本目录（UI/images/）下。账户抽屉「购买 / 续费」面板会显示它，
   客户流程：扫码加微信 → 转账 → 发付款截图 → 收激活码。
   路径配置在 UI/js/license.js 顶部的 PURCHASE.qrImage。

2. 微信收款码（可选，将来升级用）
   如果以后办了商家收款码，把收款码图（如 pay-qr.png）放进本目录，
   并把 PURCHASE.qrImage 改成它，客户就能直接扫码付款、无需加好友。
   记得同步更新 i18n.js 里 license.buy.step1~3 的流程文案。

图片缺失时面板会显示「未配置」提示并引导用文字联系方式，不会露出破图。
建议宽度 600 像素以内，JPG / PNG 均可。
