Ollama 免费开源，安装后模型的下载与推理都在本机完成，断网也能用。

  1. 下载并安装 Ollama（Windows 安装包约 700MB），按提示装完即可。
  2. 打开 PowerShell，拉取一个模型（首次下载约 1～4GB）：
    ollama pull qwen2.5:7b
  3. Ollama 装好后会常驻后台自启。若仍提示无法连接，先手动启动服务：
    ollama serve

llama.cpp 免费开源，通过 llama-server 提供 OpenAI 兼容接口（默认 http://localhost:8080）。

  1. 下载 llama.cpp Release（Windows 压缩包，解压即用）：
  2. 从 Hugging Face 下载 GGUF 模型文件，放入解压目录的 models 文件夹。
  3. 在解压目录打开 PowerShell 启动服务，保持窗口开启：
    llama-server -m models\qwen2.5-7b-instruct-q4_k_m.gguf --port 8080

数据与风险说明

使用云端模型时，你输入的文字、当前选中的表格或文档片段、以及近期对话会发送到你填写的 API 地址。该地址可能在本机以外，也可能在境外。

提供商选 Ollama 或 llama.cpp，且地址指向本机时，提示词默认留在本机。把地址改成远程服务器后，数据会发往该服务器。

部分工具会修改当前工作簿、文档或幻灯片，导出文件，或在本机运行 VBA / Python。删除、清空一类操作会先请你确认。

API 密钥只保存在本机当前用户下，不会打进安装包。请勿把 llm_config.json 发给他人。企业可把自定义 API 指到私有化模型。

聊天窗格上的撤销是插件自己的上一步，撤不回你在工作表里用 Ctrl+Z 能撤的编辑。
