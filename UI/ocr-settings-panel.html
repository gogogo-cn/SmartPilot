如果一键安装也失败，可以手动执行以下命令：
# 1. 打开命令提示符或 PowerShell
# 2. 执行以下命令（替换为实际 Python 版本号）：
py -3.9 -m pip install paddlepaddle -i https://pypi.tuna.tsinghua.edu.cn/simple
py -3.9 -m pip install paddleocr -i https://pypi.tuna.tsinghua.edu.cn/simple
# 3. 下载 OCR 识别模型（重要！）：
py -3.9 -c "from paddleocr import PaddleOCR; PaddleOCR(use_textline_orientation=True, lang='ch'); print('ok')"
