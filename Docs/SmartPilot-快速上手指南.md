# SmartPilot 快速上手指南

> 一句话认识它：SmartPilot 是一款装进 Office 的 AI 助手，Excel / Word / PowerPoint 通用，
> 你只用“说人话”，就能做表、美化、画图、分析、识别票据、生成 PPT。

---

## 一、它长在哪？（功能区入口）

安装后，在 Excel / Word / PowerPoint 顶部会出现 **SmartPilot** 选项卡，五个按钮：

| 按钮 | 作用 |
|---|---|
| **AI Chat** | 主对话窗口，所有操作都在这完成 |
| **Image OCR** | 识别图片/截图，转成表格 |
| **AI Model** | 配置大模型（首次使用需设置） |
| **OCR Model** | 配置识别引擎 |
| **Mobile** | 手机扫码，随拍录入 Excel / 遥控 |

---

## 二、5 分钟上手三步

1. **配模型**：点「AI Model」，填入模型地址和密钥，保存。
2. **选数据**：在表格里选中要处理的数据区域。
3. **说人话**：在 AI Chat 输入框直接打你的需求，回车。

> 切换语言：右上角 🌐 按钮或按 `Alt + L`（界面与功能区按钮同步中英切换）。

---

## 三、你能让它做什么（常用口令）

> 选中数据后，把下面的话直接发到 AI Chat，命令不必一字不差，说清即可。

**变好看**
- `把这张表美化成商务蓝风格`
- `科技绿 / 活力橙 / 优雅紫 / 极简灰 / 金融红 / 墨黑金 / 晴空青 美化`
- `商务蓝三线表` / `商务蓝无边框风格`
- `商务蓝美化，首列加粗、末行合计强调、数值右对齐`

**做表（不用函数）**
- `按销售额从高到低排序` / `只保留华东区的数据`
- `在最后一列加总求和` / `给这一列补全空值为 0`
- `把 A 列和 B 列合并成"姓名-部门"` / `导出为 CSV 到桌面`

**画图**
- `用饼图按部门展示销售额` / `用柱状图对比各月营收`
- `用组合图：柱状显示营收，折线显示毛利率放次坐标轴`

**清洗与分析**
- `清洗这张表：删除重复行、空值补全为0、统一日期格式`
- `把多个工作表合并成一个` / `按部门拆分到不同工作表`
- `对比新旧两个文件的差异` / `生成描述性统计`

**看板与 PPT**
- `生成一张销售数据分析看板`
- `根据这份数据生成一份 Q3 经营分析 PPT` / `用 business_blue 主题`

**识别与代码**
- 拖图到「Image OCR」，或 `识别这张截图并转成表格`
- `写一个 VBA 宏：批量把工作表按名字排序`
- `写一个 Python 脚本：对销售数据做聚类分析`（需深度/专家模式）

## 四、思考模式怎么选

AI Chat 顶部有四档，越往右能力越强、执行越自主：

| 模式 | 适合 |
|---|---|
| 快速 | 简单改表、排序筛选 |
| 标准 | 日常分析与格式化 |
| 深度 | 复杂分析、跑自定义脚本 |
| 专家 | 执行自定义 Python 等高风险脚本（安全分级放行） |

---

## 五、提问黄金公式

> **清晰目标 + 数据范围 + 期望产出**

例：`（把选中的）销售明细，做一张（用饼图展示）各部门占比的看板。`
目标越具体，结果越稳。

---

## 六、常见问题

- **界面/功能区没切换语言**：切换后若功能区没变，保存工作簿后完全关闭并重开 Office 即可（插件随进程启动加载一次）。
- **识别不准**：在「OCR Model」切换识别引擎重试。
- **生成慢**：把思考模式切到「快速」或「标准」。
- **导出成功但找不到文件**：导出默认落到桌面，可按桌面文件名搜索。
