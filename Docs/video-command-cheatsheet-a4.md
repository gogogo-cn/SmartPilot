# SmartPilot 口令速查卡 · A4 一页版（可打印贴桌）

> 用法：打印贴显示器旁。选中数据后，直接把左边“想做什么”对应的“口令”发到 AI Chat。
> 心法：**清晰目标 + 数据范围 + 期望产出**。命令不必一字不差，说清即可。

| 想做什么 | 直接说 |
|---|---|
| 表格美化 | `把这张表美化成商务蓝风格` |
| 换配色 | `科技绿 / 活力橙 / 优雅紫 / 极简灰 / 金融红 / 墨黑金 / 晴空青 美化` |
| 换版式 | `商务蓝三线表` / `商务蓝无边框风格` / `商务蓝卡片条纹` |
| 细节强调 | `商务蓝美化，首列加粗、末行合计强调、数值右对齐` |
| 排序筛选 | `按销售额从高到低排序` / `只保留华东区的数据` |
| 汇总求和 | `在最后一列加总求和` |
| 补空值 | `给这一列补全空值为 0` |
| 拼接字段 | `把 A 列和 B 列合并成“姓名-部门”` |
| 导出文件 | `导出为 CSV 到桌面` |
| 饼图 | `用饼图按部门展示销售额` |
| 柱/折线图 | `用柱状图对比各月营收` / `用折线图看毛利率趋势` |
| 组合图 | `用组合图：柱状显示营收，折线显示毛利率放次坐标轴` |
| 一键清洗 | `清洗这张表：删除重复行、空值补全为0、统一日期格式` |
| 多表合并 | `把多个工作表合并成一个` |
| 拆分 | `按部门把数据拆分到不同工作表` |
| 关联 | `两张表按客户ID关联` |
| 差异对比 | `对比新旧两个文件的差异` |
| 描述统计 | `生成描述性统计：均值、最大最小、标准差` |
| 写公式 | `写个公式：销售额大于1万且老客户标记重点` |
| 数据看板 | `生成一张销售数据分析看板` |
| 识别图片 | 拖图到「Image OCR」，或 `识别这张截图并转成表格` |
| 一键PPT | `根据这份数据生成一份 Q3 经营分析 PPT` |
| PPT换主题 | `用 business_blue 主题` |
| VBA宏 | `写一个 VBA 宏：批量把工作表按名字排序` |
| Python脚本 | `写一个 Python 脚本：对销售数据做聚类分析`（深度/专家模式） |
| 自建技能 | `新建技能：销售表自动清洗并美化为商务蓝加总计行` |

---

**功能区入口**：AI Chat（对话）· Image OCR（识别）· AI Model（配模型）· OCR Model（配识别引擎）· Mobile（手机扫码录入）
**常用设置**：中英文切换 `Alt+L`｜思考模式：快速 / 标准 / 深度 / 专家（自定义脚本需深度/专家放行）

> 完整口令见 `video-command-cheatsheet.md`（12 大类 50+ 条）。
