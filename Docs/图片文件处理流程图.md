## 当前实现说明

当前版本已使用 `processImageGeneric` 统一函数处理所有图片类型，通过 `IMAGE_PROCESSING_CONFIG` 配置对象管理不同识别类型的配置。

### 统一处理函数

```javascript
async function processImageGeneric(base64Image, fileName, type = 'general', extraInputs = {}) {
    const config = IMAGE_PROCESSING_CONFIG[type];
    // 统一处理逻辑...
}
```

### 配置对象

```javascript
const IMAGE_PROCESSING_CONFIG = {
    'invoice': { /* 发票识别配置 */ },
    'card': { /* 身份证/名片识别配置 */ },
    'table': { /* 表格识别配置 */ },
    'general': { /* 通用图片识别配置 */ }
};
```

## 后端通信协议详情

### 前端发送请求

```javascript
// 图片识别请求
{
  "type": "executeSkill",
  "skillName": "ImageRecognition",
  "inputs": {
    "imageData": "data:image/jpeg;base64,/9j/4AAQSkZJRgABAQ...",
    "fileName": "发票001.jpg",
    "operationType": "invoice"  // 或 'table', 'card', 'extractText', 'general'
  }
}
```

### 后端成功响应

```javascript
// 发票识别成功
{
  "success": true,
  "outputs": {
    "发票代码": "011001900211",
    "发票号码": "12345678",
    "开票日期": "2024-01-15",
    "金额合计": "10000.00"
  }
}
```
