一、产品简介

SmartPilot 将大语言模型与 Office 深度集成，核心特点：

  • 一套助手，三件套通用：在 Excel、Word、PowerPoint 中体验完全一致，学一次全会用。
  • 自然语言驱动：用日常说话的方式下达指令，AI 自动理解并执行。
  • 确定性引擎保障：数据导出、格式化、筛选等操作由稳定引擎执行，结果可复现。
  • 安全分级：可自定义的脚本操作需在高级模式下确认执行，防止误操作。

典型场景：日常报表处理、数据清洗与分析、经营看板制作、汇报 PPT 生成、票据/截图识别、批量文件汇总等。

二、安装与首次配置入门

2.1 认识功能区入口

安装后，Office 顶部会出现 SmartPilot 选项卡，包含五个按钮：

按钮功能
AI Chat主对话窗口，绝大多数操作在此完成
Image OCR识别图片/截图并转为表格
AI Model配置大语言模型
OCR Model配置识别引擎
Mobile手机扫码连接，遥控 Excel

2.2 配置大模型（首次使用）

  1. 点击 AI Model 按钮打开设置面板。
  2. 填入模型服务地址与 API 密钥，选择模型，保存。
  3. 保存后即可开始对话。

2.3 切换界面语言

点击右上角 🌐 按钮，或按快捷键 Alt + L，即可在中/英文之间切换，功能区按钮同步更新。

三、快速开始

三步即可完成第一个任务：

  1. 选中数据：在表格中选中要处理的单元格区域。
  2. 打开对话：点击 AI Chat，右侧弹出对话窗口。
  3. 描述需求：在输入框用自然语言说出你想做的事，回车发送。

示例：选中一张数据表后，输入 把这张表美化成商务蓝风格，表格会在瞬间套用配色与格式。

十、数据看板与大屏

选中数据，一句话生成可投屏看板：生成一张销售数据分析看板。

看板会自动组合核心指标卡、趋势图、占比图等模块。可进一步 生成经营分析大屏、把看板导出成网页/图片用于汇报。

十一、OCR 图片识别

  1. 点击 Image OCR，拖入或选择图片。
  2. 识别结果以结构化表格呈现，可一键写回 Excel。

识别不准时，可在 OCR Model 切换识别引擎重试；版式固定的复杂票据还可定制解析脚本批量提取字段。

十二、手机扫码录入

  1. 点击 Mobile，面板中显示二维码。
  2. 用手机扫码连接。

连接后，核心用途是随拍录入：用手机拍摄纸质表格、单据等现场数据，即可直接录入 Excel，即拍即入，省去手工敲字；同时也支持在手机端进行简单遥控。

十三、Word / PPT 表格主题

表格美化同样适用于 Word 与 PowerPoint。在 Word / PPT 中选中表格，输入 商务蓝美化 或 活力橙三线表，即可统一风格。

十八、思考模式与安全策略

模式适用场景
快速简单改表、排序、筛选
标准日常分析与格式化
深度复杂分析、执行自定义脚本
专家执行自定义 Python 等高风险脚本

安全分级：自定义脚本在「标准」及以下会被拦截，需切换到「深度」或「专家」才会执行。日常建议保持中低档。

十九、提问技巧与最佳实践

提问黄金公式

清晰目标 + 数据范围 + 期望产出，例：把选中的销售明细，做一张用饼图展示各部门占比的看板。

  • 先选数据再提问。
  • 复杂任务分步说。
  • 导出/格式化/筛选走确定性引擎，报成功即代表已生成、可复现。
  • 识别不准换 OCR 引擎，生成慢切「快速」模式。

二十、常见问题（FAQ）

Q：切换语言后功能区按钮没变？
A：保存工作簿并完全关闭、重开 Office 即可。

Q：识别图片不准确？
A：在「OCR Model」切换引擎重试；固定版式票据可定制解析脚本。

Q：生成速度慢？
A：将思考模式切换为「快速」或「标准」。

Q：导出成功但找不到文件？
A：默认保存到桌面，可在桌面按文件名搜索。

Q：自定义脚本无法运行？
A：需在「深度」或「专家」模式下执行。

Q：一套设置三件套通用吗？
A：界面与能力一致；模型、语言按宿主独立保存，可分别配置。
