# SmartPilot 视频教程 · 竖屏封面文字版式规范

> 配套 `video-tutorial-scripts.md` 与 `video-tutorial-assets.md`。
> 用途：把每集封面标题，转成可直接在剪映/PS/Canva 里落的竖屏封面排版。
> 画布建议：1080 × 1920（9:16），安全区上下各留约 220px 避开平台 UI。

---

## 一、封面版式规范（四区）

```
┌─────────────────────────┐
│                         │  ← 顶部安全区（不放关键文字）
│   [角标] AI办公 · 第N集   │  ← 角标区：小字，右上或左上
│                         │
│                         │
│      【主标题大字】       │  ← 主标题区：≤12字，最粗，占视觉中心
│                         │
│     副标题 / 结果        │  ← 副标区：小于主标，讲结果或卖点
│                         │
│   [界面截图/前后对比]     │  ← 图示区：软件界面或“前→后”对比
│                         │
│     一句话钩子（可选）    │  ← 钩子区：小字，置于底部
│                         │  ← 底部安全区
└─────────────────────────┘
```

### 排版参数（可直接套用）
- **主标题**：字号 130–160px，思源黑体/阿里巴巴普惠体 Heavy，纯白或明黄，可加黑色描边+轻微投影；字间距 -2。
- **副标题**：字号 60–72px，中等字重，颜色 #FFE066（黄）或 #FFFFFF；放在主标题下方 20px。
- **角标**：字号 36–40px，圆角半透明黑底 + 白字，右上角，内容如「AI办公 · 第3集」。
- **钩子**：字号 40px，底部居中，可省略（钩子也可做成视频前3秒字幕）。
- **配色**：主色 SmartPilot 蓝紫渐变（#4F7CFF→#7A5CFF）；主标题与背景对比度要高（深底白字或白底深色）。
- **图示区**：软件界面截图去背或加圆角，右侧放“美化后”，左侧放“原始”并打 ✗，形成前后对比。

## 三、可直接复制的封面文案（三套风格）

### A. 痛点反差风（适合入门集 1–8）
- 大字：**不会函数也做表**
- 副标：排序、筛选、求和，说人话就行
- 角标：AI办公 · 第4集
- 图示：左边“疯狂敲公式 ✗”，右边“一句话 ✓”

### B. 结果爽感风（适合进阶集 9–16）
- 大字：**数据大屏一键出**
- 副标：ECharts 看板，直接投屏开会
- 角标：AI办公 · 第9集
- 图示：满屏炫酷看板 + “一键生成”按钮高亮

### C. 专业进阶风（适合高阶集 17–24）
- 大字：**经营分析一条龙**
- 副标：清洗→美化→图表→看板→PPT
- 角标：AI办公 · 第23集
- 图示：五步流程链缩略图，末端是 PPT 封面

## 四、出图小贴士
- 主标题一旦确定，全系列保持同一字体、同一位置、同一描边，形成栏目辨识度。
- “前后对比”图示转化率最高，优先用于美化/清洗/图表类集。
- 抖音/视频号可在封面加“>”手势或箭头指向主标题，引导视线。
- 封面文字与视频前 3 秒钩子保持一致，减少跳出率。
