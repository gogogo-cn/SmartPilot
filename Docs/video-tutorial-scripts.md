## 阶段一 · 入门

### 第 1 集《产品初识与安装》
- **时长**：4–5 分钟
- **学习目标**：认识 SmartPilot 是什么，能在 Excel/Word/PPT 里找到并使用它。
- **分镜脚本**：
  1. 画面：桌面打开 Excel，顶部出现「SmartPilot」选项卡。旁白：今天给大家介绍一款装进 Office 里的 AI 助手——SmartPilot，Excel、Word、PowerPoint 都能用。
  2. 画面：逐个点开功能区按钮（AI Chat / Image OCR / AI Model / OCR Model / Mobile）。旁白：它的核心入口就这五个按钮：AI Chat 是主对话；Image OCR 识别图片；AI Model 配模型；OCR Model 配识别引擎；Mobile 手机扫码，把拍的表格、单据直接录入 Excel。
  3. 画面：演示在 Word、PPT 里同样出现 SmartPilot 选项卡。旁白：一套 AI，三件套通用，不用学三遍。
  4. 画面：打开任务窗格（侧边 AI Chat 面板）。旁白：点 AI Chat，右侧就弹出对话窗，后面所有操作都在这里完成。
- **必演示口令**：无（纯界面认知）。
- **收尾话术**：装好插件，找到 SmartPilot 选项卡，你就已经站在了起跑线上。下一集，我们让 AI 真正连上网。

### 第 2 集《第一次对话：连上你的 AI》
- **时长**：5 分钟
- **学习目标**：完成模型配置，发出第一条有效指令。
- **分镜脚本**：
  1. 画面：点「AI Model」按钮，打开设置面板。旁白：第一次用要先告诉它用哪个大模型。
  2. 画面：填写/选择模型与 API Key（打码敏感信息），保存。旁白：填入你的模型地址和密钥，保存即可，支持中英文界面。
  3. 画面：演示右上角 🌐 语言按钮 / Alt+L 切换中英文。旁白：界面看不懂？点这个地球图标或按 Alt+L，一键中英切换，功能区按钮也会同步变语言。
  4. 画面：回到 AI Chat，输入“你好，介绍一下你能做什么”。旁白：发出第一条消息，确认连接成功。
- **必演示口令**：「你好，介绍一下你能做什么」
- **收尾话术**：模型和语言都配好了，接下来我们直接上手做第一张漂亮的表。

### 第 3 集《表格一键美化》
- **时长**：6 分钟
- **学习目标**：用自然语言把普通表格秒变专业报表。
- **分镜脚本**：
  1. 画面：一张丑丑的原始数据表。旁白：很多人做表就这样，灰白底、没边框，拿去汇报很掉价。
  2. 画面：在 AI Chat 输入“把这张表美化成商务蓝风格”。表格瞬间变色。旁白：一句话，商务蓝配色 + 标准网格就套好了。
  3. 画面：依次演示“科技绿美化”“活力橙美化”“优雅紫”“极简灰”“金融红”“墨黑金”“晴空青”。旁白：内置 8 套配色，直接说名字就能换。
  4. 画面：演示版式——“商务蓝无边框风格”“商务蓝三线表”“商务蓝卡片条纹”。旁白：除了颜色，还有 10 种版式：网格、深表头、三线表、无边框、卡片条纹、下划线表头……配色和版式可以自由组合。
  5. 画面：演示“首列加粗、末行合计强调、数值右对齐”。旁白：对齐、强调、行高这些细节，也能一句话搞定。
- **必演示口令**：「把这张表美化成商务蓝风格」、「科技绿美化」、「商务蓝三线表」、「商务蓝无边框风格」
- **收尾话术**：配色×版式，几十种组合随你挑。下一集，我们不光要好看，还要好用。

### 第 4 集《不会函数也能做表》
- **时长**：6 分钟
- **学习目标**：用自然语言完成增删改查、排序、筛选、汇总。
- **分镜脚本**：
  1. 画面：选中一片数据，输入“给这一列补全空值为0”。旁白：不用记函数，直接说需求。
  2. 画面：演示“按销售额从高到低排序”“只保留华东区的数据”“在最后一列加总求和”。旁白：排序、筛选、求和，全是自然语言。
  3. 画面：演示“把 A 列和 B 列合并成‘姓名-部门’”。旁白：字段拼接、格式转换也一样说。
  4. 画面：演示“把这张表导出为 CSV 到桌面”。旁白：导出文件也一句话，路径自动落到桌面。
- **必演示口令**：「按销售额从高到低排序」、「只保留华东区的数据」、「在最后一列加总求和」、「导出为 CSV 到桌面」
- **收尾话术**：函数记不住没关系，AI 替你写。下一集，我们用一句话画出图表。

### 第 5 集《一句话生成图表》
- **时长**：5 分钟
- **学习目标**：自然语言生成并定制图表。
- **分镜脚本**：
  1. 画面：选中销售数据，输入“用饼图按部门展示销售额”。旁白：AI 自动选饼图，按部门汇总。
  2. 画面：演示“用柱状图对比各月营收”“用折线图看毛利率趋势”。旁白：柱、折、饼、组合图，说类型就出图。
  3. 画面：演示“在图表下方加一句洞察：营收8月达峰”。旁白：还能顺手配上数据结论。
- **必演示口令**：「用饼图按部门展示销售额」、「用柱状图对比各月营收」、「用折线图看毛利率趋势」
- **收尾话术**：图表不再是难点。进阶篇，我们开始真正提效。

## 阶段二 · 进阶

### 第 6 集《数据清洗不求人》
- **时长**：6 分钟
- **学习目标**：用 SmartDataCleaner 批量规范化脏数据。
- **分镜脚本**：
  1. 画面：展示重复行、空值、格式不一的表。旁白：脏数据最耗时间。
  2. 画面：输入“清洗这张表：删除重复行、空值补全为0、统一日期格式”。旁白：一键清洗三件套。
  3. 画面：演示“把‘男/女性’规范成 M/F”“去掉前后空格”。旁白：文本规范化也一句话。
- **必演示口令**：「清洗这张表：删除重复行、空值补全为0、统一日期格式」
- **收尾话术**：脏活累活交给 AI。下一集，数据分析全家桶。

### 第 7 集《数据分析全家桶》
- **时长**：8 分钟
- **学习目标**：掌握合并、拆分、关联、差异、描述统计五大分析技能。
- **分镜脚本**：
  1. 画面：「把多个工作表合并成一个」。旁白：多表合并，DataMerger 一键。
  2. 画面：「按部门把数据拆分到不同工作表」。旁白：拆分用 DataSplitter。
  3. 画面：「用订单表和客户表按客户ID关联」。旁白：TableJoiner 做 VLOOKUP 级别的关联。
  4. 画面：「对比新旧两个文件的差异」。旁白：DataDiffAnalyzer 找出改了什么。
  5. 画面：「生成这张表的描述性统计：均值、最大最小、标准差」。旁白：DescriptiveStatsReporter 出报表。
- **必演示口令**：「把多个工作表合并成一个」、「按部门拆分到不同工作表」、「两张表按客户ID关联」、「对比两个文件差异」、「生成描述性统计」
- **收尾话术**：分析五件套，覆盖 80% 办公场景。下一集，公式不再背。

### 第 8 集《公式助手》
- **时长**：5 分钟
- **学习目标**：用 SmartFormulaAssistant 自然语言生成公式。
- **分镜脚本**：
  1. 画面：输入“写个公式：如果销售额大于1万且是老客户，标记‘重点’，否则‘普通’”。旁白：AI 直接给你 IF+AND 嵌套公式。
  2. 画面：演示“算每个月的环比增长率”“按条件求和 SUMIFS”。旁白：复杂公式说人话就行。
  3. 画面：公式插入单元格并正确计算。旁白：生成即可用，不用自己改。
- **必演示口令**：「写个公式：销售额大于1万且老客户标记重点」、「算每月环比增长率」
- **收尾话术**：公式助手，让函数门槛降到零。下一集，做一块数据大屏。

### 第 9 集《数据看板与大屏》
- **时长**：7 分钟
- **学习目标**：用 DashboardGenerator 一句话生成可视化大屏。
- **分镜脚本**：
  1. 画面：选中销售明细，输入“生成一张销售数据分析看板”。旁白：AI 自动挑选图表组合，生成 ECharts 大屏。
  2. 画面：展示多卡片 KPI + 柱/折/饼组合。旁白：首页核心指标、趋势、占比一次齐活。
  3. 画面：演示“把看板导出成网页/图片用于汇报”。旁白：可直接投屏或导出。
- **必演示口令**：「生成一张销售数据分析看板」、「生成经营分析大屏」
- **收尾话术**：汇报不再手搓 PPT 图表。下一集，拍照就能变表格。

### 第 10 集《拍照即表格：OCR》
- **时长**：6 分钟
- **学习目标**：用 Image OCR 把图片/截图转成可编辑表格。
- **分镜脚本**：
  1. 画面：点「Image OCR」，拖入一张报表截图。旁白：纸质表、截图表，统统能识别。
  2. 画面：识别结果以结构化表格呈现，可一键写回 Excel。旁白：识别完直接落到单元格。
  3. 画面：演示「OCR Model」切换识别引擎。旁白：识别不准时换引擎试试。
- **必演示口令**：「识别这张截图并转成表格」
- **收尾话术**：相机一拍，表格到手。下一集，用手机把拍的表格单据直接录进 Excel。

### 第 11 集《手机扫码录入》

- **收尾话术**：手机一拍，数据就进表。下一集，把风格延伸到 Word/PPT。

### 第 12 集《Word/PPT 表格主题》

## 阶段三 · 高阶

### 第 14 集《一键生成 PPT 报告》
- **时长**：7 分钟
- **学习目标**：用 GeneratePPTReport 从 Excel 数据直接出演示文稿。
- **分镜脚本**：
  1. 画面：选中数据，输入“根据这份数据生成一份 Q3 经营分析 PPT”。旁白：AI 自动组织封面、KPI、图表、结论。
  2. 画面：生成的 .pptx 自动打开，含图表页与洞察。旁白：数据驱动，不用自己排版。
  3. 画面：演示换主题“business_blue”。旁白：换个主题就是另一份风格。
- **必演示口令**：「根据这份数据生成一份 Q3 经营分析 PPT」、「用 business_blue 主题」
- **收尾话术**：从数据到汇报，一键直达。下一集，复杂 PPT 怎么迭代。

### 第 15 集《PPT 分步构建》
- **时长**：8 分钟
- **学习目标**：用分步工具搭建复杂、可迭代的 PPT。
- **分镜脚本**：
  1. 画面：演示“创建 PPT 项目，标题‘2026 发布会’”。旁白：先建项目拿到 projectId。
  2. 画面：依次“加封面 / 加目录 / 加图表页 / 加 KPI 页 / 加结构时间线 / 加致谢”。旁白：一页一页拼，边做边确认。
  3. 画面：演示“把第3页图表改成组合图”“删除第5页”“重新渲染”。旁白：随时改、随时重渲。
  4. 画面：点渲染，.pptx 生成。旁白：复杂报告也能精细控制。
- **必演示口令**：「创建 PPT 项目：2026 发布会」、「加封面页」、「加图表页：营收趋势」、「把第3页改成组合图」、「重新生成 PPT」
- **收尾话术**：分步构建，复杂汇报也从容。下一集，深入代码级自动化。

### 第 16 集《VBA 与 Python 生成》
- **时长**：7 分钟
- **学习目标**：用 GenerateVBA / GeneratePython 做深度自定义。
- **分镜脚本**：
  1. 画面：输入“写一个 VBA 宏：批量把工作表按名字排序”。旁白：GenerateVBA 直接产出可运行宏。
  2. 画面：输入“写一个 Python 脚本：对销售数据做聚类分析并出图”。旁白：GeneratePython 生成分析脚本（需在深度/专家模式执行）。
  3. 画面：提示专家模式安全分级。旁白：自定义脚本在专家模式放行，日常模式自动拦截，安全可控。
- **必演示口令**：「写一个 VBA 宏批量重命名工作表」、「写一个 Python 脚本做销售聚类分析」
- **收尾话术**：不会写代码也能拥有代码能力。下一集，认识全部技能。

### 第 17 集《26 个内置技能地图》
- **时长**：6 分钟
- **学习目标**：建立技能选择心智模型。
- **分镜脚本**：
  1. 画面：列出技能分组——美化（SmartTableBeautifier）、图表（SmartChartWizard）、清洗（SmartDataCleaner）、分析（SmartDataAnalyzer/SmartSummary）、数据（合并/拆分/关联/差异/描述统计/多文件）、文档（Word/PPT 主题）、生成（VBA/Python/PPT/OCR脚本）、工具（ExcelCRUD/ImageFieldExtractor/SalesReport/HtmlBrowserDisplay/ThinkingFramework）。
  2. 画面：给出“什么时候用哪个”速查。旁白：记住这张地图，遇事不慌。
- **必演示口令**：无（地图讲解）。
- **收尾话术**：技能是积木，下一集我们造自己的积木。

### 第 18 集《自建技能 SkillCreator》
- **时长**：7 分钟
