# SmartPilot 口令速查卡（用户可截图照做）

> 在 Excel/Word/PPT 的 AI Chat 面板里，直接复制下面的“人话”发送即可。
> 建议：选中数据或区域后再发，AI 更懂你要处理的对象。
> 提示：命令不必一模一样，说清「目标 + 数据范围 + 期望结果」就能用。

---

## 一、表格美化
| 想做什么 | 直接说 |
|---|---|
| 一键套配色 | `把这张表美化成商务蓝风格` |
| 换配色 | `科技绿美化` / `活力橙美化` / `优雅紫美化` / `极简灰美化` / `金融红美化` / `墨黑金美化` / `晴空青美化` |
| 换版式 | `商务蓝三线表` / `商务蓝无边框风格` / `商务蓝卡片条纹` / `商务蓝下划线表头` |
| 细节强调 | `商务蓝美化，首列加粗、末行合计强调、数值右对齐` |
| Word/PPT 同款 | 在 Word/PPT 选中表格后说 `商务蓝美化` / `活力橙三线表` |

## 二、数据操作（不用函数）

## 十二、设置与模式
| 想做什么 | 在哪做 |
|---|---|
| 配模型 | 功能区「AI Model」按钮，填模型地址 + Key |
| 配识别引擎 | 功能区「OCR Model」按钮 |
| 中英文切换 | 右上角 🌐 按钮 或按 `Alt + L` |
| 思考模式 | AI Chat 面板顶部：快速 / 标准 / 深度 / 专家（自定义脚本需深度/专家放行） |
| 手机扫码录入 | 功能区「Mobile」按钮，扫码连接后拍照录入 Excel |

---

### 提问黄金公式
> **清晰目标 + 数据范围 + 期望产出**
> 例：`（把选中的）销售明细，做一张（用饼图展示）各部门占比的看板。`
> 目标越具体，AI 越稳。
