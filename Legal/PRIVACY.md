# SmartPilot 隐私说明

生效日期：2026-10-11

本说明告诉你：哪些内容会离开这台电脑、哪些只留在本机、企业如何改用私有模型。对外发布前，把「【运营方】」换成营业执照主体。

## 1. 谁处理

本软件由 **【运营方】** 提供。你填写的模型服务商（OpenAI、Azure、通义、DeepSeek、私有化接口等）是独立的处理者，按其自己的条款处理你发去的内容。

## 2. 什么会发到模型

当你使用 **云端模型** 时，为完成这一次对话，本软件会把下面的内容发送到 **你在设置里填写的 API 地址**：

- 你输入的文字；
- 当前选中的表格、文档或幻灯片片段，以及完成本步所需的近期对话；
- 工具调用所需的参数（例如区域地址、表头）。

该地址由你决定，可能在本机以外，也可能在中国境外。本软件没有自己的中转服务器；数据去向就是这个地址。

当你把提供商设为 **Ollama 或 llama.cpp**，且地址是本机（localhost / 127.0.0.1）时，提示词默认留在本机。若你把地址改成远程服务器，内容会发往那台服务器。

企业若不能接受数据出本机或出境：在设置里改用本机模型，或把「自定义 API」指到贵司已审批的私有化端点。不要填写公共云密钥。

## 3. 什么留在本机

- API 密钥：写入当前 Windows 用户的配置，并用该用户的 DPAPI 保护。独立服务读取的 `llm_config.json` 只放在本机用户目录或本机运行目录，权限收紧为当前用户；**安装包不应携带该文件**。**授权服务不会收集或转发你的模型 API Key。**
- Office 文件：修改发生在你打开的文件上，不会因为「保存设置」而被上传。
- 诊断导出：你在帮助里点「导出诊断信息」时，文件只含界面版本、宿主、模型服务商和 API 主机名，不含密钥、不含文档正文。是否把该文件发给支持人员由你决定。

## 3.1 账户与订阅（若你使用登录）

当你注册或登录 SmartPilot 账户时，授权服务会处理：账号标识（邮箱或手机号）、密码摘要、订阅计划与到期时间、支付服务商返回的订单号。这些数据用于验证 **软件席位** 是否有效，**不用于计量你的模型 Token**。

支付由 Stripe（海外）或微信/支付宝等（国内）处理；【运营方】不在插件内保存完整银行卡号。

本软件当前 **没有** 默认开启的崩溃自动上报。

## 4. 本机还会执行的操作

部分工具会改文件、导出文件，或在本机运行 VBA / Python。这些代码在你的电脑上执行，不经过【运营方】的服务器。删除、清空一类操作会先弹确认。

## 5. 保存多久、如何删除

密钥和模型设置保存在本机，直到你在设置里更换、或卸载并删除：

- `%APPDATA%\ExcelAIVSTOAddIn\`
- 各宿主运行目录下的 `Config\llm_config.json`（若存在）

卸载 Office 加载项不会自动清空上述目录。不再使用时请手动删除。

## 5.1 身份证等证件

身份证属于敏感个人信息。只在你确有业务需要时使用识别。本地识别引擎在本机处理图片；若你改用云 OCR，图片会发到你填写的那个服务商。授权服务不接收证件图片，也不接收识别出的姓名和号码。

识别结果写进你打开的工作簿，或留在本机 OCR 历史里。不再需要时，从工作簿删除对应内容，并在 OCR 工作台的历史里删除记录。

## 6. 我们不做什么

【运营方】不出售你的表格或文档。在你没有另行接入统计服务之前，本软件也不把使用记录发到【运营方】。

模型服务商可能按其条款保留请求日志。这不在本软件控制范围内，购买或配置模型时请阅读该服务商的隐私政策。
